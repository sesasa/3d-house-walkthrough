Added curved/reclining seating, sewn cushion edges, woven scatter cushions and table linen, bedside drawer details, window handles and roller blinds, cabinet drawers and glazed contents, small photo-backed countertop objects, scanned plants, supported pendant lights, and detailed boundary leaves.

Eight precomputed room reflection maps replace generic-only indoor reflections. Live bathroom mirrors remain available. Source geometry and the edited GLB preserve separate named objects; the browser batches static geometry for rendering and idles while the camera is still.

## Limitations

This is a manually reconstructed model. Photo-derived furnishings are illustrative; materials and illumination are not measured. Opening heights, sills, exact fitted module widths/depths and ceiling heights still need physical measurements. The outdoor context is approximate. The revised hall step is a better constrained interpretation of the main plan, not a verified measurement.

No source photos from number 13 were used as references for number 5. Only reusable generic assets and rendering techniques were carried over. No number 13 application files were edited, and no RunPod was started for this refinement.
